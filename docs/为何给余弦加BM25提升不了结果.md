# 为何给余弦加 BM25 提升不了最终结果

> 状态：已定案（2026-08-14 实测；2026-08-15 删除并集后定稿）  
> 配套：[为何把混合方案改成 BM25 托底](./为何把混合方案改成BM25托底.md) · [需求说明](./需求.md)

本文回答一个问题：**为什么 BM25 无论"加在判决里"还是"加在召回里"，都提升不了最终结果。**

我们试过两种加法，都被实测证伪，最终两条都删掉了。

---

## 1. 加法一：判决混合（0.7·cos + 0.3·bm25）——减分

**数学上方向就错了**：只要 `bm25 < cos`，混合分就小于纯 cos。

换说法型真重复的 bm25（0~0.39）远低于 cos（0.61~0.82），掺入即精确打击"临界带"，把该过的对拖下线。实测算账（α=0.7）：

- 0.6B 模型：0.7 阈值命中从纯 cos 的 **8/9 掉到 6/9**
- 8B 模型：0.75 阈值命中从 9/9 掉到 **6/9**（0.777 的换说法对被拖到 0.649）

BM25 高分的对（标点/选项重排/公式）余弦本来就 ≥0.98——掺了是冗余；BM25 低分的对（换说法）掺了是减分。**BM25 对判决分的贡献恒 ≤ 0**，任何模型、任何比例、任何阈值下都不如纯 cos。

（完整论证与数据见 [为何把混合方案改成 BM25 托底](./为何把混合方案改成BM25托底.md) §3。）

---

## 2. 加法二：召回并集（BM25 Top50 ∪ 余弦 Top50）——零贡献

**实测**：66 题特征集上，余弦 Top50 / 并集 / 余弦 Top200 三种召回在所有阈值下**输出完全相同**；并集多捞的 167 对精确 cos 全部 ≤0.33，滑条最低 0.50——**任何滑条位置都不可见**。0.6B 下同样逐格相同。

**为什么零贡献是结构性的，不是样本巧合**：

```
BM25 的成功集 ⊆ 字面重叠集 ⊆ 正常 embedding 的高余弦集
```

- BM25 能给高分的，只有字面重叠型；字面重叠（文本几乎全同）在正常 embedding 里必然极端高余弦（近复制是小扰动，模型对 indomain 文本近似光滑）。
- 极端高余弦在万级、K=50 下名次极稳（66 题集实测真重复余弦排名：8B ≤3、0.6B ≤6，离 50 有 8 倍以上余量）。
- 余弦真正可能漏的（换说法、弱字面重叠），BM25 给 0 分、连自己的 Top50 都进不去——并集对这类对是死的。

**所以并集要么捞回被余弦滤掉的东西（死代码），要么捞进同模板变式题（假阳性，污染候选）。** 66 题集测不到肥簇效应，"排名 ≤6"不能外推成万级仍 ≤6；但集合包含关系可以外推：n 变大时最先掉出 Top50 的是换说法那一侧——恰是 BM25 救不了的一侧。

### 与 Grok Build 的交叉印证（2026-08-15）

Grok-4.6 独立分析（仅凭问题框架与实验结论，无代码/数据访问）得出同一结论：

- 该场景（余弦 rank>50 且 BM25 rank≤50）**条件存在、默认设定下接近不存在**，只在「短题干 × 模板题海 × 弱表征」交汇处罕见出现——例如判断题模板海（"下列表述正确的是"）、古诗文默写、法条摘句。
- 并集不是中性保险：BM25 高分、余弦中等的候选主体是同模板变式题。终判纯 cos 时并集是死代码；**若将来终判改成 max/RRF/加权，并集会立即变成精度杀手**。
- 真出问题的正确补救是修表征/调 K，不是加回第二条召回通道。

我们保留的反驳：Grok 把"短文本坍缩"判为罕见，但**判断题（无选项、最短、模板化最重）是题库主流题型**，0.6B 用户在判断题题海上的漏检风险它未给量化答案——这是删并集后的真实代价，缓解手段只有调 K 或升模型（见 §4）。

---

## 3. 定案后的架构

```
读表 → 尝试向量服务
        ├─ 成功     → 余弦 Top50 → 判决 = 纯余弦
        └─ 失败/未配 → BM25 Top50 → 判决 = BM25 相对分（托底，UI 提示）
```

两条路径互不共享融合逻辑。BM25 的算力只在托底时付出（有向量服务时全程不算 BM25）。

---

## 4. 出路与复评条件

如果真实题库出现「明明几乎一样却没查出来」：

1. **先调余弦 K**：`app/retrieve.py` 的 `TOP_K=50` 提到 100。对 0.95+ 的字面近复制，K=50 已远超所需；调 K 救的是"肥簇里裕量偏小的近重复"，模态正确，万级上多算 50~150 个余弦邻居的成本可忽略。
2. **再升模型**：0.6B → 8B，短模板题海的表征质量质变。
3. **最后查表征**：检索文本是否被稀释（拼了解析/来源等长字段）或只嵌了超短题干——修字段，不是加通道。

**永不恢复**：判决混合（任何比例）、召回并集——前者实测减分，后者只在终判被改成 max/RRF/加权时才有价值，而那一步本身就是错的。

---

## 5. 三句话

1. **判决加 BM25 是减分**：换说法对的 bm25 远低于 cos，掺入即把临界带拖下线。  
2. **召回加 BM25 是死代码**：BM25 的成功集 ⊆ 余弦的高分集，并集捞不回任何余弦漏掉的对。  
3. **BM25 唯一该在的地方是托底**：无向量服务时整条链路交给他；有向量时它一次都不该被计算。
